省心购 API client

一个可回放的客户端：输入商品信息，确认识别结果，查看授权范围内的比较结果，并管理购后保护 case。

演示用户边界

每次认证请求都会带上这个用户 ID。它只代表当前本地演示身份，不是登录或真实账户凭证。

识别输入

支持 API 当前实现的 text、url、taobao_token 三种输入。

确认识别字段

字段值可以在本地编辑；确认接口当前只接收确认的字段名，因此编辑值会保留在本次客户端结果中，不会伪装成服务端已写回。

比较结果

结果由 API 返回，并受当前 launch policy 和 source authorization 限制。

购后保护

创建和读取 case 需要演示用户身份；路由会校验市场、来源、问题类型和责任路径。

来源与能力状态

仅展示 API 当前报告的元数据。状态为 designing 或受限时，不代表真实平台接入可用。
